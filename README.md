# ☕ Java Basics & Core Concepts - TPs

Welcome to the **Java Basics TPs** repository. This repository contains a structured collection of practical work (Travaux Pratiques) and exercises covering fundamental concepts of imperative and object-oriented programming in Java.

---

## 📁 Repository Structure

The project is organized into modular packages, each focusing on a specific algorithmic concept:

| Module / Package | Description | Key Topics |
| :--- | :--- | :--- |
| **`Affichage`** | Output operations and formatted console printing | `System.out.println`, String concatenation |
| **`Arithmetique`** | Basic arithmetic and mathematical operations | Operators (`+`, `-`, `*`, `/`, `%`) |
| **`Calculatrice`** | Implementation of a basic console calculator | Arithmetic logic, user input handling |
| **`Decision`** | Conditional execution and branching structures | `if / else`, nested conditions, `switch` |
| **`Factorielle`** | Factorial calculation using iterative loops | `for` / `while` loops, accumulators |
| **`Information_Tableau`** | Array allocation, insertion, and display | Arrays (`int[]`), index iteration, `Scanner` |
| **`Maximum`** | Finding the maximum value among inputs | Comparison logic, conditional logic |
| **`Signe`** | Checking number polarity (Positive/Negative/Zero) | Conditional validation |
| **`Somme`** | Cumulative sum calculation of numerical series | Loop accumulation, input streams |
| **`Table_de_multiplication`** | Generating formatted multiplication tables | Nested loops, dynamic formatting |
